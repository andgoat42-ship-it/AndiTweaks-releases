# Andi Tweaks

Windows performance, privacy and gaming toolkit: 170+ reversible tweaks, a Fortnite page with real ping tests, PC and BIOS checks, cleanup, startup manager and Game Boost.

## Download

**[⬇ Download AndiTweaksSetup.exe](https://github.com/andgoat42-ship-it/AndiTweaks-releases/releases/latest/download/AndiTweaksSetup.exe)** (Windows 10/11, 64-bit)

The app updates itself: when a new version is out you'll see **"Restart to update"** in the title bar.

## Install notes

- Windows may show **"Windows protected your PC"** because the installer isn't code-signed yet. Click **More info → Run anyway**.
- Andi Tweaks asks for administrator rights because most tweaks change system settings.
- Every tweak saves the original value first and can be switched back off. Creating a restore point before big changes is still a good idea (the app has a button for it).
